# Site Institucional da Inovale Jr

Este é o repositório do site institucional da Inovale Jr, Empresa Júnior vinculada aos cursos de Engenharia de Produção e Engenharia Mecânica da Universidade Federal do Ceará (UFC) - Campus Russas.

## Estrutura do Projeto

```
inovalejr-site/
├── index.html          # Página principal
├── css/
│   └── style.css      # Estilos do site
├── js/
│   └── main.js        # Scripts JavaScript
└── assets/            # Imagens e outros recursos
    ├── logo.png
    ├── hero-bg.jpg
    └── team/          # Fotos da equipe
```

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5
- Font Awesome 6

## Funcionalidades

- Design responsivo
- Navegação suave
- Animações de scroll
- Formulário de contato
- Galeria de projetos
- Seção de equipe
- Integração com redes sociais

## Como Executar

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/inovalejr-site.git
```

2. Abra o arquivo `index.html` em seu navegador ou utilize um servidor local.
